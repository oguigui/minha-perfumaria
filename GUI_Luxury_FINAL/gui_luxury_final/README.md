# GUI Luxury — Projeto Integrador

Projeto acadêmico de uma perfumaria fictícia, desenvolvido com HTML5, CSS3 e JavaScript puro.

## Como abrir
1. Extraia a pasta do projeto.
2. Abra `index.html` no navegador (ou use a extensão Live Server no VS Code).
3. Não é necessário instalar dependências.

## Estrutura
- `index.html`: conteúdo e estrutura semântica.
- `css/reset.css`: reset e box sizing.
- `css/style.css`: identidade visual, layout responsivo, navegação e componentes.
- `js/data.js`: catálogo demonstrativo com cinco perfumes.
- `js/app.js`: filtros, análise de orçamento, funções, arrays, DOM, Canvas e formulários.
- `assets/images/`: ilustrações SVG locais.

## Recursos implementados
- Navegação sticky, menu dropdown e menu compacto para telas menores.
- Catálogo com filtros por categoria e cinco itens cadastrados como objetos.
- Uso de `map`, `filter` e `reduce` na análise da coleção.
- Funções com retorno e parâmetro padrão.
- Criação de elementos com `createElement`, `textContent` e `append`.
- Gráfico Canvas 2D com conteúdo alternativo.
- Logotipo e elemento ornamental em SVG.
- Formulários com validação nativa do navegador.
- Exercício de repetição `while` com entrada via `prompt`.
- Tabela de produtos e valores atualizada pelo JavaScript.

## Observações
Os nomes, descrições e preços dos perfumes são fictícios e servem apenas para a atividade. O vídeo e o áudio são espaços demonstrativos: arquivos de mídia não foram fornecidos, então não há referências quebradas a arquivos inexistentes.

## Git e entrega
Os commits, publicação no GitHub e abertura de Pull Request precisam ser feitos na conta do aluno. Exemplo de branch: `feature/projeto-integrador-final`.
